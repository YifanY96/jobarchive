首次连接方法

在 Google Cloud 创建项目，启用 Gmail API，配置 OAuth 同意屏幕（测试模式时添加自己的 Gmail 为测试用户），创建「桌面应用」OAuth 客户端，下载 JSON 并在这里导入。随后点击连接 Gmail，完成只读授权。

仅读取邮件，不发送或删除邮件。凭据由 Windows 账号加密；同步后的邮件正文保存在本机，完整备份也会包含它们。Google 测试模式授权可能到期，需要重新连接。
